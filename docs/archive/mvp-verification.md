## ✅ Issue #9: 認証機能 テストサマリー

<br>

<br>

| テスト | ファイル | ケース数 |

<br>

**方針:** 「認証機能が壊れていないことを保証する」ため、正常系・異常系・セキュリティ（パスワード暗号化・セッション・email 一意性）を検証。過剰品質を避け、必要十分なテストに留める構成とした。

<br>

> 📌 この時点のテストは 20 runs。本リリース完了時点では **868 runs / 2309 assertions** まで拡充されています（最新のテスト状況は README を参照）。

## ✅ Issue #37: 本番環境 最終動作確認（MVP 全機能）

<br>

MVP の全機能を本番環境で確認するためのチェックリスト。対象は以下の9カテゴリ:

MVP としてリリース可能な品質であることを保証するための、詳細な最終チェックリスト。<br>
